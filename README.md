# EchoVault — Digital Time Capsule

A responsive digital time-capsule website where users can write messages to their future selves and lock them until a selected date.

## Repository Name

`echovault-time-capsule`

## Features

- Create digital time capsules
- Choose a future reveal date
- Add a title, message, mood, and color
- Countdown to each reveal date
- Search and filter capsules
- Mark capsules as favorites
- Dark and light modes
- Export and import JSON backups
- Responsive mobile design
- Private browser storage

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage
